PYTHIA · LOCAL CONNECTION GUIDE

Connect Google Calendar and Gmail

Use a Google OAuth client that belongs to you. The client secret and refresh token stay on this Mac and must never be committed.

  1. In Google Cloud Console, select or create a project.
  2. Open APIs & Services → Library and enable Google Calendar API and Gmail API.
  3. Set up the OAuth consent screen. For a personal test, choose External / Testing and add your Google account as a test user. Workspace policies may require admin approval.
  4. Create an OAuth client ID with application type Web application. Add the authorized redirect URI http://localhost:3000/auth/google/callback.
  5. In the project folder, copy .env.example to .env. Add the client ID and secret. Keep `.env` private; it is in `.gitignore`.
  6. Restart the server, open Connections, click Connect Google, and grant Calendar event and Gmail read-only access.
  7. Run Calendar Breather. Review the meeting analysis and proposed breaks. Select the events to add. Add invitee email addresses only if you want Google to send invitations to those people.

What PYTHIA accesses

  • Primary calendar events for the next five days.
  • Recent Gmail message snippets for attendees on those events (up to 30 days). It does not fetch full message bodies or save snippets.
  • Calendar events are only created after you explicitly confirm the selected breaks. Without invitees, they are private blocks on your calendar. With invitees, Google sends them invitations.

Sentiment is estimated locally with a small transparent phrase list, not an LLM. The app keeps OAuth tokens in the ignored `data/` folder with file permissions limited to your macOS user.
