PYTHIA · LOCAL CONNECTION GUIDE

Connect Google Calendar

Use a Google OAuth client that belongs to you. The client secret and refresh token stay on this Mac and must never be committed.

  1. In Google Cloud Console, select or create a project.
  2. Open APIs & Services → Library and enable Google Calendar API. Enable Gmail API only if you opt in to meeting-context analysis while planning breaks.
  3. Set up the OAuth consent screen. For a personal test, choose External / Testing and add your Google account as a test user. Workspace policies may require admin approval.
  4. Create an OAuth client ID with application type Web application. Add the authorized redirect URI http://localhost:3000/auth/google/callback.
  5. In the project folder, copy .env.example to .env. Add the client ID and secret. Keep `.env` private; it is in `.gitignore`.
  6. Restart the server, open Connections, click Connect Google, and grant Calendar event access and Gmail read-only (used only when you opt in to meeting-context analysis).
  7. Open Calendar Breather and choose 5, 10, or 15 minutes (or let PYTHIA choose what fits) and whether the Oracle should analyze once or three times daily. The Oracle decides how many breaks suit each day; accept or decline tentative holds in the PYTHIA invitation list.

What PYTHIA accesses

  • Primary calendar events and all-day busy time for the next seven days when planning recovery breaks.
  • By default, break planning does not read Gmail or send event details to the LLM. You may opt in to bounded recent email subjects/snippets and meeting titles for tone analysis; attendee addresses and full email bodies are not sent.
  • Tentative holds are added automatically. Accepting confirms the event; declining removes it. These are holds created by your own account, not incoming Google invitation emails or native Google RSVP requests.

Calendar load is not used to infer burnout or diagnose health. The LLM chooses a daily target and may name warm, lightly funny activities; you can accept or decline each hold. The local scheduler runs while the server is running; it pauses when the app is stopped and analyzes overdue work once after restart. You can pause/resume it in Connections. The app keeps OAuth tokens in the ignored `data/` folder with file permissions limited to your macOS user.
