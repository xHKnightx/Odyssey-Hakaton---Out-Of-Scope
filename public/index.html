ONE-TIME LOCAL SETUP

Configure Google access

  1. In Google Cloud Console, create or select a project. Enable Google Calendar API and Gmail API.
  2. Configure the OAuth consent screen. For testing, use External / Testing and add your Google account as a test user. Your Workspace administrator may need to allow these scopes.
  3. Create an OAuth client ID of type Web application. Add this authorized redirect URI exactly: http://localhost:3000/auth/google/callback
  4. Copy .env.example to .env in the project folder and paste the client ID and secret into it. The file is ignored by Git.
  5. Restart the app, then return here and click Connect Google. Review Google’s consent screen for Calendar event access and Gmail read-only access.

PYTHIA reads your next five days of calendar events and searches recent Gmail snippets related to meeting attendees. It estimates sentiment locally from subject/snippet text. It does not retain email snippets. Calendar events are only created after you review and confirm proposals.
