ONE-TIME LOCAL SETUP

Configure Google access

  1. In Google Cloud Console, create or select a project. Enable Google Calendar API. Enable Gmail API too if you want to opt in to email context analysis.
  2. Configure the OAuth consent screen. For testing, use External / Testing and add your Google account as a test user. Your Workspace administrator may need to allow these scopes.
  3. Create an OAuth client ID of type Web application. Add this authorized redirect URI exactly: http://localhost:3000/auth/google/callback
  4. Set OAuth client values in the ignored .env.local file, then restart the app.
  5. Return here and click Connect Google. Use the same Google account you signed in with.
